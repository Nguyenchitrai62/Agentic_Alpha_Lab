# K2EVAL 2026-10-07: offline K2 dip-tilt evaluator on paper runners' real dip fills

- Tool: `scripts/k2_paper_eval.py` (new) + `tests/test_k2_paper_eval.py` (5 tests pass).
- What it does: loads a paper runner's closed dip pieces from `actions.jsonl` /
  `exchange.json` / `state.json` (entry/exit parsing reused from
  `scripts/paper_report.py`: `load_actions`, `load_json`, `classify_exec`,
  `piece_of`, `load_state_links`, `piece_kind_of`, `windows_for_dir`,
  `load_corrections`), decodes holding bar T from the dip piece id
  (`bot/mirror.py` `dip_pid`: `d{phase}{COIN}{rungx10}{t36(bar)}`; T = `from36`
  suffix, `shift = phase`), joins to
  `artifacts/research/kronos_shadow/kronos_features_live.parquet` on
  `(sym, shift=phase, T)`. Only `mode == prospective` rows count; late/backfill
  reported apart. Correction windows from
  `artifacts/research/advisor_shadow/paper_corrections.json` (via
  `windows_for_dir`) exclude pieces whose exit time falls inside the window.
- P&L: gross = side*(exit_value - avg_entry*exit_qty) per closed piece (ledger
  qty 0 or exits cover entries); fees maker 0.0002 for entry/TP limits, taker
  0.00055 for stops/market exits (`bot/paper.py`); net = gross - fees.
  Counterfactual K2 P&L = k2_mult x net, normalised by mean k2_mult of the
  joined prospective pieces (equal average exposure). Reports sums, difference,
  n joined/unjoined, per coin and per T-week (Monday-start, UTC).
- Exit reason: TP link (`*T`) -> take_profit, stop (`*S`) -> stop, else the
  piece's `market_exit` reason (`time_exit` / `close5_stop` / ...), fallback market.
