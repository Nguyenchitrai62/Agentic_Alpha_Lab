## Commands that fail / flags that do not exist -> exact doc fixes (docs NOT edited)

1. **`--only` space form rejected by `restart_all.sh`** (R107; also Q32/O28
   prose `--only bots|backend|carry`). `bash scripts/restart_all.sh
   --dry-run --only bots` -> exit 2 (`usage:`), same for `backend`,
   `carry`, and the literal pipe form. Root cause: `restart_all.sh:30`
   treats a bare `--only` arg as a usage error; only `--only=X` or a bare
   positional (`bots`) reaches the space-form handler. Verified:
   `--dry-run --only=bots` -> exit 0; `--dry-run bots` -> exit 0.
   Exact fix for R107 (and the matching prose): replace
   `bash scripts/restart_all.sh --only bots|backend|carry` with
   `bash scripts/restart_all.sh --dry-run --only=bots`
   (variants: `--only=backend`, `--only=carry`). The ps1 twin
   (`.\scripts\restart_all.ps1 -DryRun -Only bots`) accepts the space form
   (verified exit 0) — no fix needed there, but the asymmetry is worth one
   line in the runbook.
2. **`--restore-list` placeholder path** (R122).
   `... --restore-list artifacts/backups/untracked_<UTC>.zip` -> exit 2,
   `restore-list: not found`. Flag exists; only the path is a placeholder.
   Exact fix: replace `<UTC>` with a real file, e.g.
   `... --restore-list artifacts/backups/untracked_20261006T102000Z.zip`
   (pick via `dir artifacts\backups`), or prefix the line with
   `REM example — replace <UTC> with a real timestamp:`.
3. **No other flag is missing.** All flags in every doc command exist in
   argparse: bot.run (`--once --mode --equity --corr-size --dip-mult
   --bear-book --dip-gross-cap --adopt-fresh --carry-f --interval --tag
   --maint-start --maint-end --risk-guard/--no-risk-guard`), carry_paper,
   bot_preflight, alert_watch, snapshot_untracked, weekly_report,
   restart_all.sh (`--dry-run`, `--only=`/positional). `run_backend.ps1`
   switches `-Status/-Background/-Stop` all exist.
