# OpenCode task oc_placebo_dip
Read AGENTS.md, research/tournament/oc_dipexit/PLAN.md + code (exact dip rung replica D0, B1 sizes via research/tournament/oc_b1deeper), and the typical PROMISING criterion of the dip screens ("4-phase-mean sum >= base in >= 4/5 years AND maxDD not worse by > 1 pp in >= 4/5"). Write ONLY research/tournament/oc_placebo_dip/ (script, REPORT.md, results.json) + tests/test_oc_placebo_dip.py. No commits. MEDIUM: RAM < 3 GB, one process (use scripts/heavy_slot.py run if one run exceeds 0.4 GB).
METHOD: false-positive rate of the dip screen. Generate 300 seeded placebo rules of the common shapes used today: (a) random rung-size multiplier x0.8 or x1.2 on a random 10-20 % of bars (chosen by a seeded hash of the bar time, never by returns), (b) random skip of 10 % of rung fills, (c) random TP x0.9/x1.1 on a random 20 % of fills. Run each through the replica on all four clock phases and score with the criterion above (and with the 'sum higher in >= 4/5' half alone). Report the pass rate per shape and per criterion half, the placebo distribution of the 5y sum delta and maxDD delta, and the stricter criterion (e.g. placebo percentile >= 95 of the 5y sum delta, or minimum effect size) that keeps false positives <= 5 %. Plain verdict line.
