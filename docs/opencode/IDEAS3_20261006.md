# IDEAS3 — 8 new untested hypotheses (2026-10-06)

Scope: BOT (G2 R2B1D17BFG2: 5.41/DD16.9) + carry add-on (+0.21/mo, oc_cashcarry) and MANUAL floor. Only: (a) structural sources w/o short-funding income, (b) execution inside user rules (one resting limit, no fill <min5, SL market + TP limit attached), (c) capital efficiency w/o raising DD. Ranked by EV/cost. Select walk-forward on 2021-2024 only; 2025 scored once. No network; data on disk per `data/raw/` 2026-10-06.

### 1. Linear-vs-inverse quarterly RV (structural) [BOT]
- Mechanism: same-expiry BTC/ETH linear (USDT-M) and inverse (coin-M) quarterlies must converge to one settlement; margin-segmentation dislocates them intraday/weekly; long cheap/short rich locks convergence, delta~0, no funding leg.
- Rule (fixed): at each oc_cashcarry roll date, if |ann.lin.basis - ann.inv.basis| >= 3pp/yr, long cheap/short rich equal notional f=0.125/coin, hold both to earlier delivery. Single threshold.
- Data: `data/raw/bybit_quarterly_20261006` (lin_BTCUSDT_*/lin_ETHUSDT_* + inv_BTCUSD*/inv_ETHUSD* + spot_*_1h.parquet).
- Test: structural sleeve accounting like oc_cashcarry (entry/delivery, fees 0.055%+0.02%/leg, MtM DD, oc_utamargin bound).
- Leakage: bases from closes <= entry bar; no imputation past last spot bar; expiries fixed by manifest.
- Effect: +0.03-0.10 %/mo when dislocated, ~0 DD (spread); fills 2025-type idle years.
- Nearest closed: oc_cashcarry (spot-vs-future outright, not cross-contract RV).

### 2. Delivery-week carry top-up (capital efficiency) [BOT+MANUAL]
- Mechanism: oc_cashcarry enters at roll (months of lockup); residual premium in the final 7d is the same convergence with days of lockup — deploys idle equity exactly when the base sleeve idles, frees capital faster.
- Rule (fixed): 7d before each BTC/ETH quarterly delivery, if ann.basis >= 4%/yr on that contract, enter spot+short f=0.125/coin, hold to delivery. Same threshold, one window.
- Data: `data/raw/bybit_quarterly_20261006` + `data/raw/qbasis_20261003` (Binance proxy cross-check).
- Test: structural sleeve accounting like oc_cashcarry, reported standalone + stacked on base carry.
- Leakage: entry uses only <= T closes; delivery = spot 4h close of delivery bar; incomplete contracts excluded.
- Effect: +0.02-0.08 %/mo, worst add-on DD < 0.4% (days-long holds); best in low-premium years.
- Nearest closed: oc_cashcarry (roll-time entry; this is late-window only) / IDEAS2#1 monthly carry (negligible — different tenor logic).

### 3. Cross-venue max-basis carry selection (structural) [BOT]
- Mechanism: same BTC/ETH quarterly premium differs Binance vs Bybit (venue segmentation); the carry rule takes whatever its single venue pays — entering on max(venues) harvests the same delivery convergence at a higher locked rate with identical structure.
- Rule (fixed): oc_cashcarry roll rule, but ENTER iff max(Binance, Bybit ann.basis) >= 4%/yr and execute the max venue's contract, f=0.25/coin. No other change.
- Data: `data/raw/qbasis_20261003` + `data/raw/bybit_quarterly_20261006`.
- Test: structural sleeve accounting (per-venue attribution + max rule), venue fees as charged.
- Leakage: each venue basis as-of its own timestamps; no cross-venue lookahead; walk-forward union where both covered.
- Effect: +0.02-0.07 %/mo via higher locked rate + fewer skips; DD flat.
- Nearest closed: oc_cashcarry (single-venue Binance proxy) / research/data_fetch/bybitq (availability, not selection).

### 4. Near-vs-far quarterly roll-down spread (structural) [BOT]
- Mechanism: in contango the far contract decays faster than the near into the same settlement path; long near/short far (same coin, adjacent quarterlies) harvests differential decay, net delta small, no spot leg, no funding income.
- Rule (fixed): at each roll, if far ann.basis - near ann.basis >= 2pp/yr, long near/short far f=0.125/coin, hold to near delivery then close both. Single threshold.
- Data: `data/raw/bybit_quarterly_20261006` (adjacent lin_BTCUSDT_* / lin_ETHUSDT_* pairs).
- Test: structural sleeve accounting like oc_cashcarry + oc_utamargin spread-bound check.
- Leakage: pair bases <= entry bar; overlapping pairs sized additively, never netted ex post.
- Effect: +0.0-0.08 %/mo, ~0 DD; fails cleanly if curve rarely steep.
- Nearest closed: oc_carryfar (outright FAR holding — this is a spread, not a directional FAR position).

### 5. Perp-vs-quarterly convergence sleeve (structural, no spot) [BOT]
- Mechanism: same as carry but long leg is the perp (not spot): long perp + short quarterly when quarterly premium high. Saves spot fees/spot-leg logistics, margin-native on all-BTC/ETH books; under gate the perp long pays adverse funding, so the rule only enters when locked ann.basis >= 8%/yr (funding drag pre-covered).
- Rule (fixed): at roll dates, ENTER iff quarterly ann.basis >= 8%/yr, long perp/short quarterly equal notional f=0.125/coin, hold to delivery. Single threshold.
- Data: `data/raw/bybit_quarterly_20261006` + `data/raw/binance_usdm` (perp closes) + `data/raw/binance_premium_20260928` (funding path for cost row).
- Test: structural sleeve accounting (funding charged 0.01%/8h on perp long; convergence P&L net of it).
- Leakage: basis/funding known <= entry bar; never use realised settlement funding for entry.
- Effect: +0.0-0.06 %/mo net; fewer entries than spot carry by construction.
- Nearest closed: oc_cashcarry (spot long leg; this is perp leg with funding-aware threshold) / oc_basisbook NO (basis tilt, not convergence hold).

### 6. Mark-trigger stops (execution) [BOT]
- Mechanism: oc_stopslip: 7.2% of Bybit stops never touched on Binance — venue wicks stop out last-price triggers; Bybit supports mark-price trigger; mark (index + premium MA) wicks less than last, cutting false stop-outs while keeping the same market-stop protection.
- Rule (fixed): every book/dip stop triggers on reconstructed mark (index 1m close + trailing-5m premium mean), exits at next-minute open taker. Trigger only; distances unchanged.
- Data: `data/raw/bybit_linear_1m_20261004` + `data/raw/binance_premium_20260928` (premium-index 1m); `data/raw/binance_usdm` cross-check.
- Test: full 4-phase engine (v421 wiring) vs G2 base; stop-slip S4 row decides honesty.
- Leakage: mark uses premium <= trigger minute only; 1m trade-through for exit; stop-first on same-bar SL/TP ties; minute-5 rule kept.
- Effect: +0.0-0.08 %/mo via fewer wick stops, DD -0.0-0.3pp; venue-sensitive.
- Nearest closed: oc_stopslip (diagnostic, no rule) / IDEAS2#3 stop-LIMIT (order TYPE — this is trigger REFERENCE, market stop kept).

### 7. Native TP attached at fill minute (execution) [BOT]
- Mechanism: engine TPs act from the next minute; real OCO attaches SL+TP at the fill — the first post-fill minutes hold the snapback (oc_ladderfill: fast fills revert best) that a delayed TP misses; same +1.0sg level, earlier attach only.
- Rule (fixed): every dip-rung TP limit (+1.0sg, reduce-only post-only) is live from the fill minute (trade-through fill), not the next bar. Timing only.
- Data: existing majors 1m (`data/raw/majors_intraday_20260924` + `data/raw/bybit_linear_1m_20261004`).
- Test: full 4-phase engine vs G2 base; report TP-hit share + maker-share rows.
- Leakage: TP fill needs 1m trade-through strictly after fill minute; no same-tick fill+TP; stop-first ties kept.
- Effect: +0.02-0.08 %/mo if snapback thesis holds; DD flat.
- Nearest closed: oc_dipexit (exit LEVELS — this is attach TIMING at fixed TP) / oc_bybittp (venue TP asymmetry, no timing rule).

### 8. Two-hour dip-bid expiry (execution + capital) [BOT]
- Mechanism: dip rungs rest to the next 4h open; stale rungs sit through regime change and pin gross-cap headroom (oc_kpi: dip notional to ~6.4x w/o cap); unfilled-after-2h rungs are stale quotes — cancelling at +2h frees cap for fresh bars at no extra order (still one resting bid at a time).
- Rule (fixed): unfilled dip rung cancelled 2h after placement (single TTL, no replacement same bar). One parameter.
- Data: existing 1m as #7; no new data.
- Test: dip replica + placebo gate (full PROMISING legs + dSum5y >= +0.273); full engine only if passed.
- Leakage: TTL from placement timestamp only; depths from trailing sigma360 <= bar close; minute-5 rule kept.
- Effect: +0.0-0.05 %/mo + cap-headroom/DD -0.0-0.2pp; fails cleanly if late fills are the winners.
- Nearest closed: oc_holdext/oc_condhold (hold PAST open — opposite direction) / oc_earlystart (early ENTRY — this is early CANCEL).

Rank (EV/cost): 1 > 2 > 3 > 4 > 5 > 6 > 7 > 8. Structural sleeves (1-5) test cheapest; engine rules (6-7) cost more; #8 needs dip-replica + placebo gate first.
