Read AGENTS.md, docs/BOT_EXECUTION.md, bot/*.py (read only). Write ONLY bot/risk_guard.py (new module) and tests/test_bot_risk_guard.py. Do NOT edit other bot files (another worker is editing them). No commits, no network, no credentials, never touch .env.
Build an independent PRE-TRADE risk guard for live mode (to be wired in later by the leader): `check(orders, positions, equity, prices, limits) -> (allowed_orders, rejections)` where orders/positions use the bot's Order / piece fields. Limits (defaults, all configurable): per-coin gross notional <= 2.5x equity; total dip notional (open + resting entry bids) <= 2.0x equity; total gross notional <= 4x equity; any single order notional <= 1.0x equity; reject any non-reduce-only Market order (user rule: market only for stops / exits); reject entries on symbols outside BTC/ETH/SOL/BNB/XRP; reject orders whose price deviates > 15 % from the last price (fat-finger); never block reduce-only exits or protection orders. Pure functions, no I/O. Thorough unit tests. Report (<= 8 lines) at the end.
