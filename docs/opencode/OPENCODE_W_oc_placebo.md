# OpenCode task oc_placebo
Read AGENTS.md, research/tournament/oc_dvolshort (vectorised BOT book screen code), research/tournament/oc_expirybook/REPORT.md and research/tournament/oc_cmegap/REPORT.md (both PROMISING in the vectorised screen) and research/diagnostics/oc_expiry4p/REPORT.md + research/diagnostics/oc_cmegap4p/REPORT.md (both NO in the full 4-phase engine). Write ONLY research/tournament/oc_placebo/ (script, REPORT.md, results.json) + tests/test_oc_placebo.py. No commits. LIGHT: vectorised only, no engine runs, RAM < 1.5 GB.
METHOD (placebo / false-positive rate of the screen): generate 1,000 random rules of the same shape as the two promising ones: (a) "halve book targets (both sides) on a random set of contiguous 12-bar windows, one per month, at a random day" (expiry-like, ~4 % of bars) and (b) "long x0.75 or x1.25 with random sign on random 2-4 day windows, ~10 per year" (CME-like, ~1.5 % of bars). Seeded RNG, windows drawn without looking at returns. Apply each through the same vectorised screen (v410 bear filter first, 0.05 % per unit turnover) and the same PROMISING criteria as each original report. Report: share of placebo rules that pass each criterion (the false-positive rate), the placebo distribution of 5y book P&L delta and maxDD delta vs the two real rules' values (percentile ranks), and a recommendation for a stricter screen criterion (e.g. effect size or placebo-percentile >= 95) that keeps the false-positive rate <= 5 %. Plain verdict line.
