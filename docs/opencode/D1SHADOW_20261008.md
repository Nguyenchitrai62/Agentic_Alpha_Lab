# D1 shadow log (prospective downside-share dip tilt, 4 clocks x 5 majors, hourly)

- What: `scripts/d1_shadow.py --once` logs one row per (sym, shift, T) whose
  4h bar opened in the last hour (5 rows/run; `--backfill-hours N` labels N
  hours as backfill, never prospective). Feature EXACTLY as
  `research/tournament/oc_downshare` (D1: trailing-6d downside-RV share,
  share(r[E-36..E-1]), r = close-to-close 4h log returns; NaN unless all 36
  finite and total > 0; causal, only closes of bars closing <= T).
  D1 rule with the frozen anchor-2026 fit (direction +1, q20 0.2902893279,
  q80 0.7411885301, hi/lo 1.25/0.75) written in BOTH d1_mult and k2_mult.
- Venue: Binance USD-M public 1h klines aggregated to 4h (same venue and
  OHLCV+quote-volume convention as `build_bars_4shift.py` -> NO venue
  difference). A 4h close is the last 1h close of its block = the last 1m
  close, so 1h aggregation gives the same value (proven by parity: exact).
- Output: `artifacts/research/d1_shadow/d1_features_live.parquet`
  (sym, shift, T, risk_D1, C0, d1_mult + k2_mult copy, model_sha, logged_at,
  mode, is_prospective). k2_mult is an exact copy of d1_mult so the existing
  bot flag --k2-tilt reads it with no code change. PROSPECTIVE iff
  logged_at - T <= 30 min. Idempotent on (sym, shift, T). CPU only (no model).
- Parity (research/tournament/bot_d1shadow/d1_parity.parquet, 2760 rows
  2026-09-01..2026-09-23; parity_report.json): vs oc_downshare parquet on
  (sym, shift, T) — feature max abs diff 0.0 (2745/2745 overlap; 15 late-shift
  rows 21:00-23:00 have no research counterpart since that table ends
  2026-09-23 20:00, same pattern as the C2 parity); multiplier with the
  anchor-2025 fit matches exactly (2745/2745); C0 vs prior-bar research close
  exact (0.0, 2760/2760). Backfill rows are mode=backfill, never prospective.
- Leader start (CPU-light, no heavy_slot; 10 min is fine, idempotent per bar):
  `while 1; do .venv/Scripts/python.exe scripts/d1_shadow.py --once; sleep 600; done`
  (run with nohup in the background; never starts the paper runner itself).
- Paper runner (needs no code change; backfill rows map to 1.0, only
  prospective/late rows tilt):
  `python -m bot.run --mode paper --equity 5000 --corr-size --dip-mult 1.7 --dip-gross-cap 2.0 --bear-book --adopt-fresh --interval 25 --k2-tilt artifacts/research/d1_shadow/d1_features_live.parquet --tag d17bfg2d1`
- Offline eval (after >= 8 weeks): join prospective rows to the paper runner's
  dip fills by (sym, shift, T); compare sum(d1_mult x rung P&L) vs sum(rung P&L)
  at equal average exposure (divide by mean d1_mult first).
- Verify: `.venv/Scripts/python.exe scripts/d1_shadow.py --once --dry-run`
  then `.venv/Scripts/python.exe -m pytest tests/test_d1_shadow.py -q` (6/6).
  Do not start the loop or the runner yourself.
