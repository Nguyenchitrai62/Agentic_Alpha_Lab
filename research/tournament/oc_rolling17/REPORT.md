# oc_rolling17 REPORT — rolling 12-month windows, 4-phase 1/4 reset (2026-10-06; PLAN pre-registered before any outcome)

## Setup
Generalised `reset_metric.year_reset` to an arbitrary midnight-UTC anchor a0
(same hourly grid g0=2021-09-24 04:00 UTC .. g1=2026-09-23 12:00 UTC, same
b/seg/es/ms/pk: b = last e1<=a0 else 1.0; seg = (idx>a0)&(idx<=a0+365d);
es/ms = mean over 4 shifts; R = 100*(es_end^(1/12)-1); DD = 100*max(1-ms/peak(es));
losing = R<0). Scored from `v411/v411_runs.pkl` only (v406 checked for presence).
R2-4P key ("R2-4P"/"R2_4P"/"R2") is absent from both v411_runs.pkl
([R2B1D17BF, R2B1D16]) and v406_runs.pkl ([R2B1D16, R2B1D18B08, R2B1_130]), so only
R2B1D17BF (primary) + R2B1D16 (reference) are reported. 49 windows: 24th of each
month 2021-09-24..2025-09-24. No 1m data, one process, read to 2026-09-24 00:00 UTC
via cached runs; all five years are research data, needs prospective validation.
Repro: `research/tournament/oc_rolling17/{PLAN.md,run_rolling17.py,results.json}`.

## Reproduction proof (gate)
window_reset vs `reset_metric.year_reset` on the five standard anchors: max |dR| = 0.0,
max |dDD| = 0.0; vs `v411_result.json` years rows: max diff = 0.0 (tolerance 1e-3).
Standard anchors reproduced exactly, e.g. R2B1D17BF (2.831/12.42, 3.505/16.23,
4.669/18.33, 11.270/8.26, 5.060/12.81) and R2B1D16 (2.012/15.16, 3.716/16.12,
4.522/17.33, 10.788/7.85, 4.853/12.68).
